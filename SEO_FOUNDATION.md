# SEO content foundation — DIL & DATA

This note is for editorial planning, not keyword stuffing.
Build topical authority with real writing, then wire internal links.

Canonical site: https://www.dilanddata.in/

## Pillar map (use only shelves that have real stories)

```
Home (/)
  ├── Stories (/blogs)                    ← main story index (sitelink candidate)
  ├── Categories (/categories)            ← hub of shelves
  │     ├── /categories/{slug}            ← one pillar per active Studio category
  │     │     └── /blogs/{slug}           ← supporting articles in that shelf
  │     └── (Travel / Books / Culture…)   ← create in Studio when content exists
  ├── About (/about)                      ← person / publication context
  └── Contact (/contact)
```

## How to grow a shelf (example: Travel)

1. Create category **Travel** in Studio → Categories (layout: Standard).
2. Publish 3+ genuine travel stories assigned to Travel.
3. From each article: category badge + “Filed under Travel” + related posts.
4. From Travel archive: list of stories + link back to Stories and Categories.
5. Optionally mention Travel from About or a home Features block with a real link.

## Internal linking rules

- Every article links to its category archive.
- Related posts: same category, up to 5, only when they exist.
- Breadcrumbs: Home → Stories → Category → Article.
- Nav labels: Stories, Categories, About, Contact (clear sitelink candidates).
- Do not invent empty Travel/Culture/Ideas/Books pages “for SEO.”

## Studio SEO defaults (recommended)

Title: `DIL & DATA | Stories, Travel, Culture & Ideas`

Description (~155 chars):  
`DIL & DATA is an independent personal publication exploring stories, travel, culture, books, people, and the quietly ridiculous details of everyday life.`

Canonical base: `https://www.dilanddata.in`

OG image: upload a 1200×630 share image in Studio → SEO.

## Preferred Sources

Google’s Preferred Sources is managed in Search Console / Google app settings for readers.
Do not add a fake “Add as preferred source” button unless Google publishes an official embed for this site type.
